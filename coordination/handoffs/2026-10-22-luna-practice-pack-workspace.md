## Decisions and limits

- The component consumes frozen authored packs and reducer/export APIs only. It does not edit model, router, app shell, shared CSS, package configuration or manifests.
- Before submit, the presenter does not pass disposition, criterion IDs or rationale to the view. Feedback is displayed only after a reducer action, and scripted revisions only after the corresponding step is reached.
- Rejected choice and help history remain visible. No answer is auto-selected or inferred. All scoring language follows the underlying model’s formative, unverified provenance.
- Session data stays in memory. The JSON export is generated by `exportRun`; the UI reports a download request, not receipt.
- Browser interaction and download completion were not tested. This deliverable is not wired into a route; root owns integration and aggregate build review.
