## First three original prototypes

`design/module-motion-20261023/` demonstrates:

1. **Economics:** solve `Qd = 100 + shift − P`, `Qs = 20 + P`; distinguish a demand shift from movement along a fixed curve. This is a bounded linear toy market, not a forecast.
2. **Accounting:** owner contributes R1,000; buy units at R10; sell at R15; cash/inventory/profit stay linked and the simplified accounting equation balances. No VAT, credit terms, expenses or full financial-reporting claim.
3. **Database concepts:** a lost response and repeated stock-change request; compare deduplication to an unsafe replay. This is an authored state illustration, not a real network/SQL engine; the full transaction lab needs concurrency/atomicity tests separately.

The prototype offers a prediction and worked explanation; it does not automatically grade free text. It exports the learner's own working as Markdown with an authored-example label. Linking it to real module-source citations, saved progress and Rain's shared voice/session controller is future integration through the existing contract owner.
