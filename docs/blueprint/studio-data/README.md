## What the health search established

Reusable anatomy **atlases and viewers** exist. [Open Anatomy Project](https://www.openanatomy.org/) supplies atlases and browser tooling; [Open Anatomy Atlas](https://github.com/CognitionLabSNUC/open-anatomy-atlas) describes full-body exploration, sections and quizzes and separates MIT application code from anatomical-data licences. It is a candidate to inspect, not an independently tested turnkey dependency. Neither establishes a complete KAIRO health-sciences curriculum, physiological simulation, approved clinical case bank or validated medical tutor.

[Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy) provides useful geometry but its own credits include separately licensed contributions, including noncommercial inner-ear and kidney material. Select and trace exact meshes. [Servier Medical Art](https://smart.servier.com/) supplies medical illustrations for complementary lightweight explanations; inspect its current terms and the selected assets. [PTB-XL 1.0.3](https://www.physionet.org/content/ptb-xl/1.0.3/) is an open CC-BY-4.0 ECG dataset candidate; use small attributed reviewed subsets only after acquisition checks, not a mandatory multigigabyte download. It is not a beating-heart mesh or patient simulator.

Important correction to a common assumption: the currently inspected [OpenStax Anatomy and Physiology 2e preface](https://openstax.org/books/anatomy-and-physiology-2e/pages/preface) states **CC BY-NC-SA 4.0**. Do not assume this particular edition is cleared for commercial KAIRO content reuse because other resources are open. Linking for discovery and copying into a commercial RAG library are different uses.

## Where the data is today

Live filesystem metadata check found **26 extracted local documents / 108 chunks**, **6 app source records**, **3 of those sources marked reviewed**, and **3 saved lesson records**. Those flags/counts do not establish educator validation or complete-document extraction. The older inventory summary lists 537 course files and 2,091 unclassified screenshots; that is an inventory, not 2,628 processed learning resources.

Private material remains under `data/private/`. Existing public discovery links, employer snapshots, model catalogues and asset manifests are useful but fragmented. There is no verified unified cloud database/hybrid-vector retrieval platform in the inspected foundation. This package adds an actual **local research-metadata registry**, not a claim that all those datasets have now been ingested or deployed.

## Forage and credentials

Use [Forage's official catalogue](https://www.theforage.com/simulations) to discover job simulations and direct learners to the provider. Its page describes self-paced example tasks and certificates suitable as extracurricular activity. That does not make them employment, an employer offer, a professional licence or an accredited degree. Task text/videos/example solutions are not automatically licensed for copying, embedding, redistribution or training. The terms page returned a shell without readable substantive terms in this check: permission is unresolved, not approved.

Store provider/title/link, competencies, prerequisites, task type, access/cost notes, checked date and completion-proof type. Create **original KAIRO tasks** using permitted public/synthetic data to practise the same competencies, clearly labelled as KAIRO-authored rather than partner-endorsed. Only add a learner's external certificate after their confirmation and provider-verification evidence where available. Do not automate obtaining a certificate or copying answer keys.

[Microsoft Credentials](https://learn.microsoft.com/en-us/credentials/) distinguishes certifications and Applied Skills; [IBM SkillsBuild adult learning](https://skillsbuild.org/adult-learners) provides a further credential/discovery route. Each exact programme's eligibility, costs, expiry and credential status must be checked. No generic “all certificates free” or “guaranteed employment” claim is supported.
