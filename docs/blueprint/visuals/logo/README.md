# KAIRO logo kit

The mark combines an open book (learning), a rising passage/gateway (spatial exploration), and a small speech cue (conversation). It is original vector artwork created for this proposal. It is provisional; the user has not selected it, and no trademark search has been performed.

## Files

- `kairo-lockup.svg`: horizontal color wordmark for documents and product surfaces.
- `kairo-shirt-badge.svg`: compact shield badge for a shirt, lanyard or event patch.
- `kairo-icon-mono.svg`: single-ink icon with transparent background for stamps, small UI, or one-color print.
- `kairo-contact-sheet.svg`: self-contained local vector sheet with the wordmark, shirt badge, and mono icon shown together.
- All are editable SVG source and use system sans-serif fallbacks rather than embedded fonts.

## Palette

- Charcoal `#252820`
- Warm cream `#F4EBDD`
- Muted olive `#87906A`
- Soft gold `#E6C47A`
- Clay `#C78755`

Use charcoal or cream for the main mark. Keep gold and clay as accents; do not put small accent strokes on low-contrast backgrounds. The single-color variant uses only charcoal ink; for another ink, replace that one fill/stroke color consistently and keep the background transparent. Preserve at least the width of the inner speech cue as clear space around the lockup. Do not stretch, rotate, outline the wordmark, or add an unreviewed slogan. For embroidery, use the badge at 55 mm or larger and request a stitch test; fine speech strokes may need simplification by the vendor.

No browser or print proof is claimed. Check contrast and reproduction on the selected garment, thread colors and actual output process before use.
