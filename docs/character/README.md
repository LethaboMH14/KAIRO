# KAIRO teaching character (CHARACTER-002)

An original, softly stylised adult teacher. She is derived from Blender Studio's Rain v3 rig (CC-BY 4.0), with a reshaped face and figure, new skin and eye textures, an authored locs updo, a sage shirt, cream trousers and gold accents. She ships as one web GLB with:
- 31 face shapes baked from Rain's own face controls;
- 30 hand correctives;
- five KAIRO-authored teaching clips;
- a runtime that points at real scene targets with arm IK.

## Using the component

```tsx
import TeacherCharacter from './character/TeacherCharacter';

<Canvas shadows>
  <Suspense fallback={null}>
    <group position={[0, 0, 0]}>
      <TeacherCharacter
        cue={{ id: 'c12', type: 'point', targetId: 'formula' }}
        targets={[{ id: 'formula', position: [0.6, 1.35, -0.2], normal: [-0.5, 0, 0.85] }]}
        audio={teacher.audioSignal}          // a ref is fine; energy never re-renders React
        expression="neutral"
        reducedMotion={prefersReducedMotion}
        onReady={report => {}}
        onCueState={event => {}}             // accepted -> acting -> one of completed | interrupted | unsupported
      />
    </group>
  </Suspense>
</Canvas>
```

- **Cues:**
  - `idle`, `listen` and `explain` cross-fade to a posture and complete when the fade ends.
  - `acknowledge` completes when its clip ends.
  - `point` resolves `targetId` in `targets`, which are world positions:
    - A missing id returns `unsupported` with reason `target-not-found`.
    - If the target is within reach and `contact` is not `never`, the fingertip approaches and stops about 8 mm off the surface, along `normal`.
    - Otherwise she points along the ray from the shoulder.
    - `completed` means the pose is held on the target. The board does not change itself: the host performs its own allowed action, then sends `acknowledge`.
  - `move` returns `unsupported` with reason `locomotion-not-delivered`. No sliding walk is offered.
- **Interruption:** a new cue makes the unfinished one emit `interrupted` before the new one is accepted. Each arm has its own blend weight and smoothed target, so a new target or side blends from the current pose. No id receives two terminal events.
- **Audio:**
  - `energy` opens the jaw (amplitude only, labelled as such).
  - `visemes` (`{at, shape, weight}`, Rhubarb shapes A–H and X) drive phoneme-timed mouth shapes, but only when real timings for that exact audio are supplied.
  - `paused`, or `playing: false`, closes the mouth.
- **Reduced motion:** turns off idle sway, beat gestures, hair springs, saccades, speech nods and camera glides. Posture changes and pointing settle in about 0.15 s into static teaching states.
- **Testing hook:** `instrument` (optional) reports fingertip-to-target distance, gaze, head position, wrist and fingertip positions, mouth and blink about four times a second.
- **Layering:** every frame starts from the clip pose. three.js only rewrites a bone whose animated value changed, so without this the gaze, IK and spring rotations would pile up on constant or frozen (reduced-motion) tracks.

## Limits

- **Lip sync:** phoneme-timed mouth shapes exist only for the three pre-analysed samples. Live speech elsewhere still drives the mouth from loudness unless the host supplies real viseme timings (a server-side Rhubarb pass or a provider viseme stream).
- **Hands:** gestures are teaching gestures, not SASL. The hand rig can articulate, but no signing has been authored or reviewed.
- **Walking:** no locomotion or foot contact. `move` is honestly unsupported.
- **Pointing:** contact pointing is a fingertip IK target with a hover offset. It is not a physics contact and does not detect collisions with arbitrary geometry.
- **Correctives:** finger correctives are re-driven at runtime. Rain's wrist, elbow and leg correctives are not, because those areas are covered by clothing or sit outside the driven set.
- **Blender-only features lost in export:** Rain's B-bone curvature, head lattice, corrective-smooth and action-constraint face rig. The face survives as baked shapes; body bends use twist-bone splits.
- **Hair:** the locs are rigid tubes. The hanging back locs and the face-framing locs move on spring chains with collision spheres for the neck, back, shoulders and cheeks. `hair_clearance.py` checks the bind pose only, so a strong pose can still bring a loc close to the shirt.
- **Performance:** measured on one laptop GPU only (see `verification.md`). The teacher GLB has 229,366 triangles (head 50,540, body 41,964, updo locs 28,410); a rehearsal frame draws about 450,000 because the shadow pass draws her a second time. Phones are not measured and would need a lighter level of detail.
