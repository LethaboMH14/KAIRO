# KAIRO first-use and recovery audit

**Checked:** 2026-10-24
**Scope:** Read-only source audit of Home → material → review → lesson → engineering → practice → evidence → resume, and the account boundary.
**Judging lens:** Product completeness and Usability clarity/recovery.
**Method:** Read current UI/source, local verification reports and owner handoffs; checked official product help/blog pages for interaction patterns. No application was opened or driven. No learner records were read. No app code or status artifacts were changed. This is not browser, device, accessibility, learner or release acceptance.

## What a learner can do now

**Update after parent integration review on 2026-10-24:** root reports the source/route goal-selection change is mounted. Source review confirms SourceWorkspace sends the goal for both local and cloud generation, the cloud consent label says “selected for my learning goal,” the route verifies the full reviewed revision before calling selectEvidence, and the returned lesson carries evidenceSelection/coverage. The selector searches the reviewed text under the 48,000-character/100-section bounds and selects up to 12,000 characters; it is lexical matching, not semantic retrieval. Root reports tests/goal-evidence-integration.test.mjs passes with late-text evidence, exact anchors and stale rejection; final full suite and build remain pending. This audit did not execute that test. Search of learner-facing Studio source found no remaining “first 12k” prefix claim; remaining 12,000 references describe the selector/input cap.

The local preview already offers a coherent, cited learning path: choose material or paste the public sample, inspect and edit extraction, confirm a reviewed revision, shape a lesson, read/practise, keep work and resume. The source reader offers direct source passage help, and the classroom can fall back to text. Recovery copy protects earlier local work in several corruption/conflict cases.

The product boundary is easy to misunderstand unless the learner encounters the right labels. The active lesson journey still uses a local workspace and browser storage. A new private hosted API and Identity Platform setup have real two-account progress-record CRUD/isolation evidence, but the learner login route, account-bound sources/lessons and the joined journey are not integrated. An optional source-copy control is a separate, explicitly consented single-user cloud pilot; it is not account sync. A learner must not be told that current KAIRO work automatically follows an account across devices.

## Product pattern comparison (official material; checked 2026-10-24)

- **Source grounding:** Google’s Notebook help documents selecting source sets for Q&A and linking answers to cited passages. Transferable idea: show which reviewed passages support a result and keep a direct way back to the original. KAIRO already exposes citations and source review; its visible selection/coverage through lesson generation needs to be clearer. This is an interaction-pattern comparison, not feature or quality parity. [Gemini Notebook Help: add or discover sources](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en) and [Notebook notes as sources and citation chips](https://support.google.com/gemininotebook/answer/16262519?hl=en).
- **Practice next steps:** Khan Academy’s official mastery guide describes per-skill state changes after exercises/quizzes/tests and feedback on changed skill levels. Transferable idea: tie a suggested next action to the actual attempt and explain why. KAIRO’s progress page already does this with simple recorded-answer rules; keep it explicitly non-predictive and do not copy mastery percentages/claims without a validated assessment model. [Khan Academy Help: self-paced practice and Mastery](https://support.khanacademy.org/hc/en-us/articles/360007253831-Using-self-paced-practice-and-Mastery-in-the-classroom).
- **Mistake recovery:** Duolingo’s official Practice Hub description offers review of previous mistakes; its Explain My Answer post describes learner-controlled, in-lesson explanation of an answer. Transferable idea: let the learner request a small, timely explanation and revisit a missed item. KAIRO has “I’m stuck,” cited passage help and retry actions, but no claim of spaced-repetition or validated adaptive sequencing. [Duolingo: Practice Hub](https://blog.duolingo.com/guide-to-duolingo-practice-hub/) and [Duolingo: Explain My Answer](https://blog.duolingo.com/explain-my-answer-now-free/).
