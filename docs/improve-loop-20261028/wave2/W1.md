# Wave 2 lane W1: interface-language foundation

## Judging fit

- **Criteria/subquestions:** Usability — easy to use and clear next actions; Sustainability — reproducible shared interface state and a reviewable language-maintenance path.
- **Learner need:** A learner who prefers Afrikaans or isiZulu needs to understand the primary navigation and learning-journey steps in their chosen interface language, with English still available and unreviewed wording clearly identified.
- **Observable acceptance check:** English remains the default; the native picker exposes only reviewed catalogues; af/zu preview changes only the scoped labels, marks each translated span with its language, and shows the fixed review-status banner; preview is never persisted; missing translations fall back to English.

## Implementation

- Added `studio/src/i18n/language.ts`, English source catalogue, and unreviewed Afrikaans and isiZulu draft catalogues. The af/zu catalogues contain only the requested destination, access, settings, educator, account, skip-link, and five flow-step labels.
- The approved plan described a `LanguageProvider`. This implementation uses a small module store with `useSyncExternalStore` and a `storage` event listener instead. That keeps the choice synchronized across the shell, flow rail, and access dialog without adding a provider mount point in the shared root. Storage reads and writes are guarded; unsupported or unreviewed stored values fail closed to English.
- `?preview-language=af|zu` overrides the current document only. It is not written to storage and displays a fixed `role="status"` banner. `<html lang>` remains English; only translated labels receive `<span lang="af|zu">`.
- The native “Interface language” select lists English and reviewed catalogues only. The linked help text explains that both drafts are waiting for a fluent reviewer. `REVIEW-NEEDED.md` lists each key, source wording, both drafts, context, reviewer, and date status.
- Stable `translationKey` values are added to the five `flowFor()` steps. Rail notes, status text, and all other copy remain English.

## Remaining gaps

- No browser checks were run per instruction. Preview rendering, keyboard interaction, screen-reader announcement, and 375 px overflow remain unverified in a browser.
- Afrikaans and isiZulu drafts have no fluent-human review. They remain unselectable and must not be described as validated translations. Reviewer names and dates are pending.
- Cross-tab storage-event behavior and storage-denied behavior are implemented but not directly exercised by the focused suite.
- No device, learner, deployment, or production acceptance is claimed.
