# W2 — recorded voice question in source lessons

Criteria: Usability, Intelligence.

Learner need: ask a question about a source passage by voice without typing. The lane uses the existing upload-based `ListeningQuestion` (recorded file, Groq transcription, editable transcript, explicit confirm). It does not open a microphone.

## Files
- `studio/src/teacher/SourceReader.tsx` (only code file edited; CRLF preserved, 35/35 lines).
  - Import of `ListeningQuestion` from `../ai-personalisation/ListeningQuestion`.
  - Placeholder changed to "e.g. Why does this step matter?".
  - `ListeningQuestion` mounted directly below the question field with `key` built from `context.id`, `context.revision`, `context.evidenceId||context.section||0` and the selection offsets `selected?.start`/`selected?.end`.
  - `onQuestion`: fills an empty question; otherwise sets `pendingVoice` and shows a `role="group"` with aria-label "Voice question ready" offering "Replace my typed question" and "Keep mine". Nothing is sent automatically.
  - `onUseTyped`: focuses the question input through `questionField` ref.
  - `pendingVoice` is cleared in the existing passage/text reset effect.

## Deviations and decisions
- No wrapper heading was added. `ListeningQuestion` already renders its own `<summary>` "Use a recorded voice question", which is the equivalent title. Its unavailable message ("Voice-file transcription is not configured here...") is shown there too.
- The key adds the passage segment (`evidenceId||section`). The spec's `sourceId:revision:start-end` alone would not remount when the passage changes but the offsets match. `sourceId` is `context.id` (no separate prop exists).
- PR #148 (natural voice) is MERGED. Its file list has no `SourceReader.tsx`, so no wait or rebase was needed.
