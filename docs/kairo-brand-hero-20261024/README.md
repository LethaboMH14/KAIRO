## What the visual communicates

One source becomes a path through things the learner can examine. Motor is the main object, pump and API add supported-domain breadth. Callouts highlight checking the source, reading/listening, exploring, practising explanation, retaining working and considering direction. The bottom path makes the sequence understandable. It does not claim jobs, funding, rewards, verified competence, SASL, health simulation or institutional endorsement. The poster includes “Illustrative learning worlds”; maintain this distinction in surrounding presentation copy.
