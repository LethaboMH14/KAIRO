# Sources and dated evidence

Source review date: **2026-10-24**. These are direct primary or official dataset/model pages. Provider support tables and model cards change; check them again at implementation time. A capability row is not evidence of measured quality. Online docs were read as data; no site UI was observed, account used, model called or content downloaded.

## Government and KAIRO

- **SA-LANG-01 — Official languages and SASL status:** [Constitution Eighteenth Amendment Act 3 of 2023](https://www.gov.za/documents/constitutional-amendments/constitution-eighteenth-amendment-act-3-2023-english-sesotho-27); [Parliament 2023 statement on SASL as the twelfth official language](https://www.parliament.gov.za/index.php/press-releases/na-approves-south-african-sign-language-12th-official-language). The amendment recognizes South African Sign Language as an official language. Do not equate it with ASL.
- **KAIRO-LOCAL-01 — Existing teacher settings:** read-only source check of `studio/src/teacher/TeacherSettings.tsx` and `studio/src/teacher/model.ts` on 2026-10-24. The selector lists en-ZA/af-ZA/zu-ZA/xh-ZA/st-ZA/tn-ZA for browser narration; cloud voice list is three UK/US English voices. The code search over `studio/src` did not find mic/ASR/VAD capture terms. This only describes inspected paths, not external browser/device services.

## Recognition, translation, speech output and interaction

- **GOOG-STT-V2 — Exact locale/model/region table:** [Cloud Speech-to-Text V2 supported languages](https://docs.cloud.google.com/speech-to-text/docs/speech-to-text-supported-languages). Checked rows include Afrikaans `af-ZA`, Sepedi `nso-ZA`, Sesotho `st-ZA`, Swati `ss-Latn-ZA`, Tsonga `ts-ZA`, Tswana `tn-Latn-ZA`, Venda `ve-ZA`, Xhosa `xh-ZA`, Zulu `zu-ZA`; support rows vary by region/model. The V2 table checked did not list `en-ZA` or Ndebele South. See also [V1 supported languages](https://docs.cloud.google.com/speech-to-text/docs/v1/speech-to-text-supported-languages), which lists `en-ZA`.
- **GOOG-STT-STREAM — Streaming feature:** [Transcribe audio from streaming input](https://docs.cloud.google.com/speech-to-text/docs/streaming-recognize); [V2 RPC reference](https://docs.cloud.google.com/speech-to-text/docs/reference/rpc/google.cloud.speech.v2). Bidirectional streaming can return recognition results as audio is sent. This is an API capability only; KAIRO does not currently wire a mic path in the checked source.
- **GOOG-TRANS — Language codes:** [Cloud Translation language support](https://docs.cloud.google.com/translate/docs/languages). Checked language table lists Afrikaans `af`, English South Africa `en-ZA`, Ndebele South `nr`, Sepedi `nso`, Sesotho `st`, Swati `ss`, Tsonga `ts`, Tswana `tn`, Xhosa `xh`, Zulu `zu`; no `ve`/Tshivenda row was found. List support does not report KAIRO task quality.
- **GOOG-TTS — Published voices:** [Cloud Text-to-Speech supported voices](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types). `af-ZA-Standard-A` appears; no `en-ZA` or other searched South African official speech-language tags were found. This vendor list is distinct from KAIRO's three selectable English voices.
- **GOOG-GEMINI-TTS — Preview voice:** [Gemini TTS](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts) lists Afrikaans as Preview. It is not evidence that the current KAIRO adapter uses it, nor that it preserves KAIRO voice identity.
- **WHISPER-REPO — Open implementation/weights:** [OpenAI Whisper README](https://github.com/openai/whisper/blob/main/README.md?plain=1) (MIT for code and model weights, with its model/data caveats); [tokenizer language map](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py). Current map lists `af` and `en`, but not the other exact SA spoken codes inspected. README says `turbo` is not trained for translation tasks and Whisper translation outputs English. This does not establish KAIRO-domain accuracy.
- **WHISPER-STREAM — API caveat:** [OpenAI Speech-to-text guide](https://developers.openai.com/api/docs/guides/speech-to-text). `whisper-1` does not support streaming in the documented API. The guide is mutable; it also documents changes/deprecations to current OpenAI speech APIs. This research did not call them or recommend routing KAIRO audio there.
- **MMS — ASR candidate:** [Meta MMS-1B card](https://huggingface.co/facebook/mms-1b) and [MMS-1B-All card and exact supported-language list](https://huggingface.co/facebook/mms-1b-all). Card lists 1B parameters, 16 kHz audio, 1,162 ISO 639-3 codes, and CC-BY-NC 4.0; the inspected exact list contains `afr`, `nso`, `tso`, `xho`, `zul`, `eng` but not `sot`, `ssw`, `tsn`, `ven` or `nbl`.
- **SEAMLESS — Multimodal speech/text candidate:** [SeamlessM4T v2 Large model card](https://huggingface.co/facebook/seamless-m4t-v2-large). 2.3B parameters; CC-BY-NC 4.0. Its table distinguishes input/source from output/target: Afrikaans source speech+text / target text; Xhosa source speech only / no target; Zulu source speech+text / target text; English source and target speech+text.
- **NLLB — Translation research candidate:** [NLLB-200 distilled 600M model card](https://huggingface.co/facebook/nllb-200-distilled-600M). CC-BY-NC 4.0; research-only; card says no production, domain-specific text, whole-document or certified translation and notes longer-than-512-token input risk.
- **FLORES — Exact translation benchmark tags:** [Meta FLORES-200 language list](https://github.com/facebookresearch/flores/blob/main/flores200/README.md). The checked list includes `afr_Latn`, `eng_Latn`, `nso_Latn`, `sot_Latn`, `ssw_Latn`, `tsn_Latn`, `tso_Latn`, `xho_Latn`, `zul_Latn`; no `nbl_Latn` or `ven_Latn` row was found. FLORES presence is not quality evidence for a KAIRO technical lesson.
- **SILERO-VAD — Candidate endpoint signal:** [Silero VAD official README](https://github.com/snakers4/silero-vad/blob/master/README.md?plain=1) and [FAQ](https://github.com/snakers4/silero-vad/wiki/FAQ). MIT; model accepts 8/16 kHz. It detects likely speech activity, not semantics, speaker identity or user turn completion.
- **MIC-STOP — Browser track stop:** [MDN `MediaStreamTrack.stop()`](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/stop). Calling stop tells the user agent that a track is no longer needed. It does not establish that a remote server has deleted an already sent recording.

## Data and licensing

- **FLEURS — Speech evaluation:** [Google FLEURS dataset card](https://huggingface.co/datasets/google/fleurs) lists CC-BY-4.0 and `af_za` among languages. It is a read-speech set, not spontaneous noisy classroom evidence; the repository data tree is large, so no file was downloaded here.
- **CV-27-AF — Afrikaans Common Voice:** [Mozilla Common Voice organization catalogue](https://mozilladatacollective.com/organization/cmfh0j9o10006ns07jq45h7xk) lists Scripted Speech 27.0 Afrikaans as CC0-1.0, 35.74 MB at review time. Use the individual current datasheet/conditions before any future use.
- **CV-27-XH — Xhosa Common Voice:** [Xhosa 27.0 dataset datasheet](https://mozilladatacollective.com/datasets/cmu60x5rv00ilo1070jbpgna2). CC0-1.0; 35 clips, 5 speakers, 0.06 h total / 0.02 h validated. Dataset forbids speaker identification and re-hosting/re-sharing.
- **CV-27-ZU — Zulu Common Voice:** [Zulu 27.0 dataset datasheet](https://mozilladatacollective.com/datasets/cmu610aue00jtnq07hnb00xio). CC0-1.0; 223 clips, 9 speakers, 0.34 h total / 0.04 h validated. Dataset forbids speaker identification and re-hosting/re-sharing.
- **CV-27-CATALOG — Other current Common Voice listings:** Same [Mozilla Data Collective catalogue](https://mozilladatacollective.com/organization/cmfh0j9o10006ns07jq45h7xk) lists Xitsonga 27.0 (1.01 MB) as well. Size is a discovery cue; inspect the datasheet and exact split counts before using. No file was downloaded.
- **SAMA — CSIR/SADiLaR corpus metadata:** [Repository item page](https://hdl.handle.net/20.500.12185/689). The page describes Afrikaans, isiXhosa, isiZulu, Sepedi, Sesotho and Tshivenda, says podcast audio is automatically segmented/transcribed, lists CC-BY-4.0, gives verification status Level 0, and exposes five files (Afrikaans/Sesotho/Sepedi/Tshivenda/Xhosa) with total size about 9.95 GB. No Zulu file appears in the listed five. Do not treat the catalogue license alone as proof of underlying broadcaster rights or verified labels.
- **SASL-UFS — SASL research lead:** [UFS Human Language Technology for SASL repository](https://github.com/ufs-za/human_language_technology_for_sasl). It identifies annotated/synthetic materials, including 3D-printed fingerspelling hands/video frames; license CC BY-NC-SA 4.0 and repository says commercialisation needs a formal data-sharing agreement. No signer-disjoint natural clip dataset was verified.

## Kaggle resource evidence

- **KAGGLE-QUOTA — Weekly quota guidance:** [Kaggle efficient GPU usage](https://www.kaggle.com/docs/efficient-gpu-usage) says weekly GPU quota is usually 30 hours or sometimes higher depending on demand/resources and tells users to monitor actual quota. This does not verify this user's account balance.
- **KAGGLE-T4 — 2026 GPU transition:** [Kaggle Staff P100 sunset announcement](https://www.kaggle.com/discussions/product-announcements/735239) says P100 retirement on 2026-09-15 and T4x2 availability with two 16 GB GPUs. Two GPUs have separate memory.
- **KAGGLE-SESSION — Runtime limits:** [Kaggle Notebooks docs](https://www.kaggle.com/docs/notebooks) currently state 12 hours for CPU/GPU notebook sessions and 20 GB autosaved `/kaggle/working`; actual session/hardware should still be checked live before any authorized future experiment.
