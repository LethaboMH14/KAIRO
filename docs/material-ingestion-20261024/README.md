# Material ingestion foundation

Run from the repository root with `tools/course_sources/.venv-ocr/Scripts/python.exe tools/material_ingestion/extract.py --input FILE [--max-units 1..200]`. The Python `run(path,max_units)` entry point enforces the same 1..200 bound. Output is schemaVersion 1 JSON with SHA256, coverage, ordered blocks, locators, unreviewed native-parser provenance, and warnings.

A coverage unit is one text section, PDF page, DOCX top-level body paragraph/table cell, PPTX slide, or nonempty XLSX cell. PPTX slide text includes native shape, group and table text followed by speaker notes; nested element locators are retained. XLSX worksheet relationship IDs map cells to the actual tab name; formulas are serialized as formulas and shared strings resolve through the workbook table. DOCX headers, footnotes, comments, nested tables and floating visuals are expressly outside the extracted body coverage. Each PDF/Office result warns that image, chart and embedded-object semantics are not extracted. These outputs are native text evidence, not semantic understanding.

Bounds: file size is stat-checked before reading (25 MiB); ZIP central directory bounds entries (20,000) and declared expansion (80 MiB) before parser access; max-units limits retained extraction to 1..200; TXT/MD counts section delimiters without splitting the full document and emits one aggregate skip for later sections. XLSX parses worksheet XML cells directly, avoiding huge sparse row gaps; it stops when the unit cap is reached and returns `discoveredUnits: null` with an explicit unknown-tail warning. Per-block text caps at 12,000 chars and JSON at 1 MiB, with omitted blocks counted as skipped. Errors appear in failures and warnings. OCR, formulas/macros execution, network and model calls are absent.

Run `cd studio; node --test tests/material-ingestion.test.mjs`. Eight synthetic tests cover >4-page PDF, blank pages flagged needsOCR, >4 PPTX slides/notes/order, DOCX locators, XLSX formulas/cells and reordered worksheet relationships, sparse far-corner coordinates, >20,000 TXT sections under a short timeout, output cap, malformed DOCX and expanded ZIP cap. Uses existing parser environment only; no install or private learner content.
