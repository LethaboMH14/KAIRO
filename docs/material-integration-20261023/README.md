# My Material: one clear task at a time

23 October 2026. Root: codex-material-20261023-p, Codex gpt-6 / unknown effort. Current route: /sources. Integration uses the published material-wave contract, not a new server or source schema.

## Delivered

- Material -> Check source -> Shape lesson. One main panel at a time; moving between panels keeps the current editor state. Selecting another source still uses the existing unsaved-work confirmation and latest-request gates.
- Selected C palette, existing Manrope, responsive wrapping, source summary and an explicit next action after review. Removed obsolete inner navigation that contradicted the shared shell.
- Editable source text plus goal, detail and activity preference. Any text correction resets the acknowledgement and prevents advancing until reviewed/saved. Original extraction comparison remains available; it is not an original-page image viewer.
- Up to three planning cards: actual source title, section locator, authored steps and an exact quotation from unchanged reviewed text. Missing or dirty review produces no citation. These are deterministic outlines, not generated lessons or semantic topic extraction.
- Depth and approach are included with the learner goal in the existing bounded cloud request. The compiler reserves space for the choices, so a long goal is shortened. Local reading still uses exact excerpts and does not consume these preferences. Preview explains this difference before creation.
- Explicit consent and existing cloud availability gate remain. Created lesson opens the existing source-classroom flow with its source/revision identity. No arbitrary source becomes a motor/pump simulation.
- Stop waiting invalidates pending UI results and stops continued extraction polling after the current request settles. An already-sent operation can still finish on the app host; this control does not claim server cancellation or prevent incurred cloud costs. Current source/draft remains visible.
- Corrected local privacy wording: app-host storage is not a production account/tenant isolation guarantee. Use public/non-sensitive material for this pilot.

## Reusable authoring decision

Keep the working React host and strict existing artifact contract. Build future lesson blocks as versioned data plus fixed, allowlisted renderers. Do not execute document-supplied HTML/JavaScript. H5P/Adapt/Tiptap/JSON Forms are researched options, not installed or integrated. See ../material-authoring-research-20261023/README.md for official sources, costs/licences and the motor card example. Rich lesson editing, export round-trip and further activity schemas require separately owned interfaces.

## Evidence and limits

focused.txt: actual component/model/host tests. full-tests.txt: full suite. build.txt: production build. verification.json records final check counts and relevant hashes.

Host harness executes the actual SourceWorkspace with deterministic hook/fetch adapters: review-stage entry, unreviewed gate, source edit acknowledgement reset, invalidated citation, goal/preferences transmission, explicit consent/revision and suppression of late results after Stop waiting. It is not a browser, React scheduler, visual, screen-reader, real audio, real cloud, learner or device test.

Not delivered: persistent brief drafts, original PDF/image side-by-side preview, saved card title/step editing, arbitrary generated worlds, original-source search/selection coverage, live learning-style inference, H5P import, public deployment or multi-user authorization. Pump route remains a separate integration task. Browser restriction and deleted schedule remain unchanged.

## Judging and learner acceptance

| Criterion | Learner/buyer need | Observable evidence | Remaining gap |
|---|---|---|---|
| Product | Reach a lesson from a reviewed source | Current host + request/late-result tests | Live learner completion |
| Creativity | Source-linked editable planning rather than disconnected studios | Three bounded cards and preference controls | Domain-specific authored activities |
| Usability | Know what to do next; recover without replacement | Three stages, dirty gate, Stop waiting tests | Device/keyboard/screen-reader observation |
| Sustainability | Reuse existing contracts and control integration cost | No added dependencies/server/schema | Deployed measured operating cost |
| Impact | Read and practise without requiring 3D/voice | Existing local reading path retained | Learning benefit and access study |
| Presentation | Show a truthful source-to-lesson sequence | Clear preview/generated distinction | Authorized demo recording/rehearsal |
| Intelligence | Adapt a request to explicit preferences and source | Deterministic compiler, revision checks | Evaluated source comprehension/adaptation |

Feelings such as calmer, confident or understood remain design intentions, not observed user findings.
