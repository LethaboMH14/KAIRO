# My Material planning controls UI

This package provides controlled goal, depth and approach inputs plus a bounded outline preview. It does not generate a lesson. The brief is intended for a cloud request only; local reading continues to use exact excerpts. This is presentation behavior, not evidence of learning gains or a validated recommendation model.

Synthetic fixture examples used in tests include a motor-field card and pump-flow card. They are explicitly test fixtures, not curriculum or source claims.

## Judging and learner need

Usability: make the next planning choices clear. Product: keep source-linked outlines distinct from generated teaching content. Creativity/Intelligence: make a source-based plan inspectable without claiming that the outline understands a learner. Impact: keep exact reading passages usable when cloud planning is unavailable. SSR tests confirm markup and controlled callbacks only; browser/device and learner validation remain open.
