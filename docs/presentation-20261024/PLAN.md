## Evidence limits

Household mobile/fixed figures overlap. Synthetic judge accounts are not university partnerships. Generated student/device/world visuals are illustrations. Native KAIRO and motor renders use actual app models, but composited interface images are reconstructed, not app recordings. Latest repository release checkpoint is dated and is not a new cloud/live/browser check.
