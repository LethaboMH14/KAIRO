KAIRO processes learner-supplied study files and text, extracted and corrected source revisions, source-linked lessons, personal practice, and optional consented AI or voice requests. The main risks are cross-account disclosure or mutation, account/session abuse, malicious or misleading uploads, stale or fabricated citations, prompt injection, unauthorized provider processing, and resource exhaustion. Hosted private APIs derive the owner from a verified Firebase session; the multi-source lesson path checks every selected owner source and immutable revision before use and rechecks provenance on reads. The current hosted service is IAM-private. The loopback preview is a separate single-user store, not a multi-user security boundary.

We use OWASP API Security Top 10, ASVS, OWASP LLM Top 10 and NIST SSDF as review references. Risk reduction includes explicit cloud-processing consent, bounded uploads and model requests, owner/version checks, strict output validation, and source-readable alternatives. Residual risks include parser isolation, distributed abuse resistance, broad runtime permissions, provider-side retention, complete deletion/recovery, and unmeasured educational correctness. We do not claim legal compliance, certification, a comprehensive vulnerability finding, or quantum-safe operation.
