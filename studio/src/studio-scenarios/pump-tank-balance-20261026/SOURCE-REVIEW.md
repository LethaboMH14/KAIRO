# Source and domain assumptions — fictional Pump Tank Balance Lab

Checked **26 October 2026**: OpenStax, *University Physics Volume 1*, §14.5 Fluid Dynamics: https://openstax.org/books/university-physics-volume-1/pages/14-5-fluid-dynamics . The chapter defines volumetric flow rate and continuity/mass conservation for incompressible fluid. The source is CC BY 4.0 (OpenStax). This project **links** to the source; it does not reproduce its figures or text. The lab's examples, model code and visual design are newly authored.

**Derivation and scope.** For a fictional constant-density fluid in a fictional reservoir during a single fixed interval, incoming volume = constant inlet L/min × minutes, requested outgoing volume = constant requested outlet L/min × minutes. Available water is initial storage + incoming. Delivered outgoing is limited by available water; unmet demand is the shortfall. Remaining water beyond the stated capacity is labelled spill; final storage is clipped to [0, capacity]. Thus `initial + inlet − requested outlet = final + spill − unmet demand` (litres). The source teaches mass conservation but does **not** validate KAIRO's invented rates, time steps, reservoir size, instantaneous spill convention or unmet-demand convention.

**Non-goals and uncertainties.** No transient hydraulics, pump performance curve, energy, pressure, control loop, losses, flow ramp-up, tank geometry, measurement uncertainty or live sensor values are modelled. This is a *discrete educational accounting model*, **not** a calibrated engineering simulator, pump-operating recommendation, industrial procedure or safety advice. Independent engineering/teaching review remains outstanding.

**Learning evidence.** Each round asks the learner to choose one flow, predict final litres and outcome, and write an explanation before revealing the computed trace. Attempts are action-only, locally exportable and replay-validated. JSON files are user-editable; they are explicitly **local-unverified**, not authenticated progress, grading, independent competency or source-revision proof. The revision marker fences this fixed concept package, not a live authenticated source.

**Accessibility intent, not device evidence.** All interactions use native form controls; numeric table and ordered trace duplicate the tank SVG; result focus is explicitly moved; reduced-motion styling and responsive width are included. Actual browser, screen-reader, keyboard, zoom and phone observations have **not** been performed. No route, account or storage integration exists.
