How we judge progress

  • Can someone explain and apply the idea independently?
  • Can a reviewer inspect the skill evidence?
  • Is each opportunity current and sourced?
  • Were the correct documents sent to the authorised destination?
  • Did an owner or learner observe a useful outcome?
  • Can the same activity work with reading, keyboard and low bandwidth?
